HOST // ホストの立て方

Supermodel3-PonMi で、Spikeout Final Edition のリンク対戦（2〜8 人）を立てて、インターネットの向こうの人に遊んでもらうまでの手順です。ホストの PC がゲームを動かし、遠くの人には画面と音を配信します。

1用意するもの

もの目安
PCWindows 10 / 11（64bit）。CPU は Core i7 / Ryzen 7 クラス以上（1コアの速さが大事です）
GPUNVIDIA がおすすめ（NVENC で配信。ドライバーだけで動き、CUDA Toolkit はいりません）。ほかの GPU でも、CPU で配信できます
回線上り 20 Mbps 以上がおすすめ。遊ぶ人が増えるほど多く使います
ルーターUPnP が有効なもの（無いときは、ポートを手で開けます → 3）
Discord指定の Discord サーバーのメンバーであること（招待リンク）
ROM自分で持っている Spikeout Final Edition の ROM（spikeofe.zip など）。配布物には入っていません

試した環境：Core i7-13700F / RTX 4070 Super で 8 人。RTX 3060 の PC でも、640×360 で 8 人を配信できました。

2ファイルを置く

  1. リリースの zip（GitHub の Releases）を、好きな場所に展開します。中に PonMi フォルダがあります。
  2. ROM のファイルを PonMi\Roms\ に入れます。
  3. 中身はこうなっています。台ごとにフォルダが分かれていて、それぞれに supermodel.exe と Config\Supermodel.ini があります。
PonMi/
├── PonLuncher.exe      ← ここから始めます
├── Config/PonLuncher.ini
├── Roms/               ← ROM を入れる
├── 00/                 ← 1人用・クライアント用
├── 01/ … 08/           ← スロット 1〜8
└── 09/                 ← サテライト（観戦用の画面）

ini は PonLuncher が START のたびに書き直します。手で書き換えるのは、Supermodel を止めているときだけにしてください。

3ネットワークの準備

Windows ファイアウォール

はじめて START したとき、Windows が supermodel.exe の通信を許可するか聞いてきます。プライベートとパブリックの両方にチェックを入れて許可してください。聞かれなかったときは、「Windows Defender ファイアウォール → アプリを許可」で、01〜08 の supermodel.exe を許可します。

ルーターのポート（UDP）

ルーターの UPnP が有効なら、STREAM のスロットが起動したときに、自動でポートを開けます。UPnP が使えないときは、ルーターの設定で次の UDP ポートを、ホストの PC の IP アドレスに転送してください。スロット n は 55000 + (n − 1) × 4 から 4 つ使います。

まとめて開けるなら 55000-55031（UDP）です。STREAM にしたスロットの分だけ開いていれば足ります。

4Discord にログイン

  1. PonMi\PonLuncher.exe を起動します。SmartScreen の警告が出たら「詳細情報 → 実行」を押してください（コード署名がないためです）。
  2. DISCORD の LOGIN を押すと、ブラウザで Discord のログイン画面が開きます。許可すると PonLuncher に戻ります。
  3. 「server member」と出れば OK です。メンバーでないときや、PonLuncher・supermodel.exe が古いときは、START が押せません（古いときは新しい版をダウンロードしてください）。

PonLuncher は 1 台の PC で 1 つだけ起動できます。2 つ目を開くと、もう開いている方が前に出ます。

5ホストの設定（HOST）

項目意味
HOST NAMEロビーに出るホストの名前
GAMEspikeofe
LINKSリンクの台数（2〜8）。下に並ぶスロットの数になります
CODECH264（ふつうはこちら。どの PC でも軽い）／ H265（同じ画質で少ないデータ。クライアントの CPU が少し重くなります）
ENCODERAUTO（NVIDIA なら NVENC、ほかは FFmpeg）／ NVENC ／ FFMPEG（CPU）
BOT CHAR ほかボットのキャラ、ルート、ボスの体力など。くわしくは PonLuncher 説明書
SATELLITE (09)ホストの PC に、遊んでいる人を順に映す観戦用の画面（09）も出します。配信はしません

8 人ぶんを同時に配信すると、ホストの PC にかなり負担がかかります。台数が多いときは、各台の解像度を 960×540 か 640×360 に下げるのがおすすめです。

6スロットを決める（SLOTS）

スロットごとに、だれが操作するかを選びます。

モードだれが遊ぶかポイント
STREAMインターネットの向こうの人ロビーに「空き」として出ます。画面と音を配信し、相手のパッドの入力を受けます。ホストの PC のパッドやキーボードでは動きません
LOCALホストの PC でパッドを使う人PAD で XINPUT（Xbox 系）／ DINPUT（アーケードスティックなど）／ DEFAULT（ini のまま）を選びます。スロット n は n 番目のパッドを使います
BOTボット人が足りない台をボットが遊びます。配信はしません
  • 全部 BOT なら、スロット 1 が自分でゲームを始めます。LOCAL や STREAM があるときは、人がスタートするまでボットは待ちます。
  • STREAM の人のボタンは、PonLuncher が START のたびに自動で設定します。クライアントのパッドのデータは、この設定に合う形（どの台でも 1 番目のパッド）で届くので、ホストのボタン設定は触らなくて大丈夫です（ini を手で変えても、次の START で元に戻ります）。割り当ては Xbox 系パッドの並びで、A＝Shift、X＝Beat、Y＝Charge、RB＝Jump、START、レバーは左スティックか十字キーです。
  • パッドは START を押す前につないでください。あとからつないだパッドは見つかりません。

7START と遊んでいる間

  1. START を押すと、スロットの台（と 09）が全部起動し、ホストがロビーに載ります。Discord のチャンネルにも、空いているスロットが自動で投稿されます。
  2. クライアントがつなぐと、PLAYER にその人の名前が出ます。
  3. 配信している台のウィンドウは、最小化してもかまいません（配信は止まりません）。

決まりごと（自動で動きます）

  • 1 つのスロットには 1 人だけ。使用中のスロットには入れません。1 つの Discord アカウントは、このホストのスロット 1 つだけです。
  • 3 分間入力がないと、その人は自動で切断されます（最後の 30 秒は警告が出ます）。
  • 切断された人のキャラは、その場で立ち止まります（ボットにはなりません）。次にそのスロットに入った人が続きを操作できます。
  • 迷惑な人がいたら、そのスロットの KICK で外せます。

8終わるとき

STOP を押すと、PonLuncher が起動した台だけを止め、ロビーからホストが消えます。ルーターに UPnP で開けたポートも閉じます。

9困ったとき

こんなとき見るところ
START が押せないDiscord にログインして「server member」と出ているか。PonLuncher と supermodel.exe が最新か
ロビーに出ているのに、だれもつなげないファイアウォールで supermodel.exe を許可したか。ルーターの UPnP が有効か、ポートを転送したか（3）
同じ家の PC からはつながるのに、外からだめルーターのポート（UPnP が効いていない）。回線によっては（CGNAT など）外から入れないことがあります
映像がカクカクする解像度を下げる、STREAM の数を減らす、ENCODER を NVENC にする（NVIDIA のとき）
LOCAL のパッドが効かないSTART の前につないだか。PAD の種類（XINPUT / DINPUT）が合っているか。Xbox 系のパッドは Windows の仕組みで 4 台までです
