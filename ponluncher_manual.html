PONLUNCHER // 説明書

PonLuncher は、Spikeout Final Edition を 2〜8 台つないで遊ぶためのホスト用ランチャーです。台ごとの設定（ini）を書き、Supermodel を順番に起動し、止めるときもまとめて閉じます。遠くの人はストリーミングで、この PC の人はパッドで、空いている台はボットで遊べます。

1準備

フォルダ

PonLuncher.exe と同じフォルダに、台ごとのフォルダ 01〜08 を置きます（PonMi 構成）。01\supermodel.exe と 01\Config\Supermodel.ini があれば、この構成として動きます。

場所中身
PonLuncher.exeこのランチャー
Config\PonLuncher.iniランチャーの設定（自動で保存）
Config\DiscordLogin.iniDiscord のログイン情報（自動で保存）
Roms\spikeofe.zipゲームの ROM。ご自身で用意してください（同梱していません）
01〜08台ごとの Supermodel（supermodel.exe、Config\Supermodel.ini、NVRAM など）
09サテライト（観戦台）。あるときだけ SATELLITE (09) が使えます
001人用。PonLuncher は使いません

はじめる前に

  • Discord：指定の Discord サーバーのメンバーでないと、ホストは始められません（3章）。
  • パッド：LOCAL の台で使うパッドは、START を押す前につないでおきます。Supermodel は、起動したあとにつないだパッドを見つけられません。
  • ファイアウォール：ストリーミングで外から人を入れるときは、Windows のファイアウォールで Supermodel の通信を許可します。

6SLOTS

台（スロット）1〜8 の、それぞれの遊び方を決めます。LINKS より後ろの行は使われず、(off) と出ます。

MODE

MODEだれが遊ぶかSTART で書く主な設定
STREAM遠くの人。ロビーから入って、映像を受けて遊ぶStreaming = 1、InputSystem = NONE、この PC の音は消す（StreamMuteLocal = 1）。操作は下の「STREAM の操作」に固定
LOCALこの PC の人。パッドで遊ぶStreaming = 0、InputSystem = sdl。SLOT n はパッド n を使う
BOTボット（AI）AIPlayer = 1。操作のキーはすべて NONE、スタートだけキーボードの 1

BOT は後ろにまとめる決まりがあります。どこかの行を BOT にすると、それより後ろの行はすべて BOT になり、変えられなくなります。人の台（STREAM・LOCAL）は、前の番号から並べてください。

PAD/CHAR

MODE によって中身が変わります。STREAM では何も出ません。

  • LOCAL のとき（PAD）：パッドの種類。
    • DEFAULT：その台の ini のボタン設定をそのまま使います。パッドの番号（JOY1 など）だけ、スロットの番号に直します。NONE になっているボタンは、XINPUT と同じ割り当てにします。
    • XINPUT：Xbox 系のパッドの割り当てを書きます。
    • DINPUT：DirectInput のスティックの割り当てを書きます。
  • BOT のとき（CHAR）：ボットのキャラ。ORIGINAL（キャラ選択のカーソルの位置のまま）、SPIKE、LINDA、TENSHIN、WHITE。
ボタンXINPUT（SLOT n）DINPUT（SLOT n）STREAM（受ける側）

PAD を DEFAULT にしたとき

DEFAULT は「その台の ini のボタン設定を生かす」選び方です。START のとき、次の 10 個のキーだけを、ひとつずつ見て書き直します。

InputStart1、InputCoin1、InputJoyUp、InputJoyDown、InputJoyLeft、InputJoyRight、InputShift、InputBeat、InputCharge、InputJump

ini に今入っている値書く値（n はスロットの番号）
空か NONEXINPUT の割り当て（上の表）を入れます。InputStart1 なら JOYn_BUTTON8。InputCoin1 は XINPUT の表に無いので NONE のまま（フリープレイなので使いません）。
それ以外中身はそのままで、JOY のあとの番号だけをスロットの番号に直します（番号の無い JOY_ も）。キーボードの割り当て（KEY_W など）は、そのまま残ります。
  • 例（SLOT 3）：JOY1_XAXIS_NEG,JOY1_POV1_LEFT → JOY3_XAXIS_NEG,JOY3_POV1_LEFT
  • 例（SLOT 3）：JOY1_BUTTON3,JOY2_BUTTON5 → JOY3_BUTTON3,JOY3_BUTTON5（どちらも 3 になります）
  • この 10 個以外（InputStart2、InputCoin2、サービス・テストのボタン、InputUISaveState などの UI の割り当て）は、ini のままです。

前に BOT で動かした台を DEFAULT の LOCAL にすると、パッドの START が効きません。BOT で START すると、操作はすべて NONE、InputStart1 は KEY_1 に書き換わります。DEFAULT にすると、レバーとボタンは NONE なので XINPUT の割り当てに戻りますが、InputStart1 は KEY_1（NONE ではない）なので JOY が無いまま残ります。スタートはキーボードの 1 だけになります。この台は、一度 XINPUT か DINPUT で START すると直ります。

  • パッドはスロットの番号に固定です。SLOT 3 なら 3 台目のパッド（JOY3）を使うので、パッドが 3 台以上つながっていないと動きません（START の前に注意が出ます）。ini で JOY2 などを指定していても、スロットの番号のパッドに置き換わるので、「この台だけ別のパッド」はできません。
  • 書き直した値は ini に保存されます。次の START では、それが「今入っている値」になります。

KICK

STREAM の台に人が入っているときだけ押せます。押すと確かめる窓が出て、「はい」でその人をその台から外します。外れた台は空き（free）に戻り、次の人が入れます。

8START と STOP

START が押せる条件

  • Discord のメンバーとして確認できている（3章）。
  • PonLuncher と supermodel.exe が新しい版である。起動したときにネットで最新の版を確かめ、古ければ START が押せなくなり、ダウンロードのページを開くか聞かれます。

START を押すと

  1. 確かめる：HOST NAME が入っているか、各台の supermodel.exe と Config\Supermodel.ini があるか、Roms\spikeofe.zip があるか、このフォルダの Supermodel がもう動いていないか。サテライトを使うなら 09 の中身も。足りないものがあれば一覧が出て、何も始めません。
  2. パッドの数：LOCAL の台がパッド n を使うのに、つながっているパッドが n 台より少なければ、注意が出ます（「はい」でそのまま始めます）。
  3. 保存して書く：ランチャーの設定を保存し、各台の ini に、ポート、ホスト名、MODE ごとの設定、ゲームとボットの設定、ログのスイッチを書きます。
  4. 起動する：サテライト 09 を先に起動し、そのあと SLOT 1 から順に 0.2 秒おきに起動します。
  5. 表示：いちばん下に Running 4 links + satellite as "名前" (public). のように出ます。

動いているあいだ

  • HOST・SLOTS・DEVELOP の設定は変えられません（STOP すると戻ります）。
  • 全部の台が終わったら、自動で STOP の状態に戻ります（All slots have exited.）。

STOP

  1. このランチャーが起動した台だけに「閉じる」を送ります。Supermodel は設定を保存して、ロビーからも抜けます。
  2. 8 秒たっても終わらない台は、強制的に終わらせます。
  3. サテライト 09 は、つないだ輪を支えているので、最後に閉じます。

動いているあいだにランチャーのウィンドウを閉じようとすると、「全部止めて終わるか」を聞かれます。「はい」で STOP してから閉じます。

台どうしのつなぎ方（この PC の中）

台は輪になってつながります。SLOT n は 1970 + n − 1 で受けて、次の台へ送ります。最後の台は SLOT 1（1970）へ戻します。サテライトを使うときは、最後の台が 09（1970 + LINKS）へ送り、09 が SLOT 1 へ戻します。

例：LINKS 4 + サテライト受ける送る先
SLOT 119701971
SLOT 219711972
SLOT 319721973
SLOT 419731974（09）
0919741970（SLOT 1）

このほか、START のたびに各台へ Network = 1、AddressOut = 127.0.0.1、LinkPlay（台の番号）、VSync = 0 を書きます。Discord への空き状況の投稿（DiscordPost）は、いちばん前の STREAM の台だけがします。

11困ったとき

こんなとき見るところ
START が押せないDISCORD の欄が緑（server member）か。いちばん下に Update required が出ていないか。
「Supermodel is already running」と出るこのフォルダの Supermodel がまだ動いています。前のものを閉じてから START してください。
LOCAL の台でパッドが効かないSTART の前にパッドをつないだか（PADS の数）。SLOT n はパッド n を使います。PAD の種類（XINPUT / DINPUT）がパッドに合っているか。
BOT にした行より後ろが変えられない決まりです（6章）。人の台を前に並べてください。
SATELLITE (09) が選べない09\supermodel.exe と 09\Config\Supermodel.ini があるか。
ボットがゲートの前で止まっているBOT CAN OPEN GATE がオフになっていないか（人がいるときだけ変えられます）。
ボットが人と違う道へ行くROUTE / ROUTE2 / ROUTE3 を、人の進む道に合わせます。
台が勝手に終わる（EXITED）SHOW CONSOLE をオンにして起動し直し、その台の黒い窓に出る内容を見ます。

部屋のパスワードの機能は、今はオフです。ロビーのホストは、だれでも入れる（public）状態で出ます。
